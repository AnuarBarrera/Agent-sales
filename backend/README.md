# Agent Sales API

API FastAPI y worker RQ de Agent Sales. El despliegue soportado de la demo se realiza desde la raíz con Docker Compose.

Este paquete requiere Python 3.12 o superior. `app/` contiene los módulos de negocio, las integraciones y los procesos de trabajo; `migrations/` contiene el esquema evolutivo de Alembic.

Consulta el README de la raíz para configurar proveedores, sesiones y acceso público.
